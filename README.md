# ✅ To-Do List Application

A simple and interactive **To-Do List** application built in **Python** 🐍 that allows users to **create**, **manage**, and **update** tasks.

---

## 🚀 Features

- 📝 Add new tasks with a **description**, **due time**, and **priority**  
- 👀 View all tasks with their **current status**, **due time**, and **priority**  
- ✔️ Mark tasks as **completed**  
- ❌ Remove tasks from the list  
- 🔍 Filter tasks by their **status** (e.g., _To Do_, _In Progress_, _Completed_)

---

## 🧰 Technologies Used

- 🐍 Python **3**
- 🧱 Basic **Object-Oriented Programming (OOP)**
